# ShopSmart - MERN Stack E-commerce Platform

ShopSmart is a modern, full-stack e-commerce application built with the MERN (MongoDB, Express, React, Node.js) stack. It features a responsive UI, secure authentication, product management, and integrated payments.

## 🚀 Live Deployment
The application is deployed on **AWS ECS (Fargate)** using a professional infrastructure-as-code (Terraform) and CI/CD (GitHub Actions) setup.

**Live Link:** [http://shopsmart-alb-1670277942.us-east-1.elb.amazonaws.com/](http://shopsmart-alb-1670277942.us-east-1.elb.amazonaws.com/)

## 🛠 Features
- **Frontend**: React.js with Vite, React Router, and Context API for state management.
- **Backend**: Node.js & Express.js API.
- **Database**: MongoDB Atlas.
- **Authentication**: JWT & Passport.js (Google OAuth).
- **Payment Gateway**: Razorpay integration.
- **Infrastructure**: AWS VPC, ECS, ECR, and Application Load Balancer.
- **DevOps**: Docker, Terraform, and GitHub Actions.

## 📦 Tech Stack
- **Client**: React, Vite, CSS3
- **Server**: Node.js, Express
- **Database**: MongoDB
- **Cloud/Infrastructure**: AWS (ECS, Fargate, ALB, ECR)
- **Deployment**: Terraform, Docker, GitHub Actions

## 🚦 How to Run Locally
1. Clone the repository.
2. Install dependencies: `npm install` in both `frontend` and `backend` folders.
3. Set up your `.env` file in the `backend` folder.
4. Run the backend: `npm run dev` (from backend folder).
5. Run the frontend: `npm run dev` (from frontend folder).
